# 🌍 AirSight - Real-Time Air Quality Intelligence

AI-powered air quality assistant that answers questions using **real-time data from 5000+ monitoring stations worldwide**.

## Features

- 💬 **Ask Questions**: "Is it safe to jog in Delhi?"
- 🔄 **Compare Cities**: Delhi vs London air quality
- 💊 **Health Advice**: Personalized recommendations
- 📊 **Raw Data**: See actual PM2.5 readings

## Tech Stack

- **Data**: OpenAQ API (5000+ sensors worldwide)
- **AI**: Cerebras LLM (ultra-low latency)
- **UI**: Gradio
- **Index**: 948 cities pre-indexed for instant search

Built for AI Championship Hackathon 2024
